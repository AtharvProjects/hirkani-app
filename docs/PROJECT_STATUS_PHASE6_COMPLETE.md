### ♿ Accessibility Guidelines
**ACCESSIBILITY_GUIDELINES.md (300 lines)**

**Standards:**
- WCAG 2.1 Level AA compliance
- Section 508 (U.S. federal)
- EN 301 549 (European)

**Four Principles:**
1. **Perceivable** - Text alternatives, color contrast, adaptable content
2. **Operable** - Keyboard accessible, navigable, no seizures
3. **Understandable** - Readable, predictable, input assistance
4. **Robust** - Compatible with assistive technologies

**Pregnancy-Specific:**
- Accommodations for fatigue, nausea, swelling
- Brain fog support (clear language)
- Large touch targets (44x44px)
- Reduced motion option

**Testing:**
- Automated (axe-core, Lighthouse)
- Manual (keyboard, screen reader, zoom)
- User testing with pregnant women
